# Excel 导入说明

## 工作表结构

推荐使用四张工作表：
1. 填写说明 - 字段填写规则
2. 食堂表 - 食堂基本信息
3. 窗口表 - 窗口信息（含所属食堂编号）
4. 菜品数据表 - 菜品详细信息

## 校验规则

- 编号不能为空
- 食堂编号、窗口编号、菜品编号不能重复
- 窗口所属食堂编号必须存在
- 菜品所属窗口和食堂编号必须匹配
- 价格必须为数字
- 供应状态必须在固定列表中
- 必填字段不能为空

## 当前数据文件

- `data/sample/` — 开发期构造 JSON 数据（可被 Git 跟踪）。当前包含 72 道菜品、5 个食堂、17 个窗口的构造数据。
- `data/import/` — 待导入的 Excel 源文件目录（被 Git 忽略）。
- `data/processed/` — 真实 Excel 转换后的结构化 JSON 数据目录（被 Git 忽略）。

> 注意：`data/sample/` 存放的是人工构造的 JSON 数据，用于开发和测试阶段。
> 真实数据应通过 Excel 导入流程进入 `data/import/` → `data/processed/`。

## 处理流程

1. 数据板块提供 Excel
2. B 本地运行导入校验
3. 校验通过后转换为 JSON 结构化数据
4. 保存到 data/processed/ 目录

完整的管理员上传功能待产品和服务条件确定后实现。

# 系统架构

## 分层结构

Browser (手机/电脑) -> GitHub Pages (前端静态文件) -> 后端 API (Node.js) -> 数据存储 (JSON/数据库)

## 模块职责

| 模块 | 职责 |
|------|------|
| 前端 (frontend/) | 学生端页面展示、交互、搜索筛选 |
| 后端 (backend/) | API 服务、业务逻辑、Excel 导入、推荐规则 |
| 数据 (data/) | Excel 源文件、处理后数据、导入错误报告 |
| 共享 (shared/) | 前后端共用的字段定义和接口约定 |
| 文档 (docs/) | 架构、数据格式、API、部署说明 |
| 测试 (tests/) | 跨模块或公共测试 |

## 调用关系

前端 -> 后端 API -> 路由 -> 控制器 -> 服务 -> 数据仓储

## 部署方案

- 前端：GitHub Pages（静态文件托管）
- 后端：学校服务器（Node.js API 服务）
- 数据：学校服务器文件系统

# 项目决策记录

## 已确定内容

- 前端：Vue 3 + Vite，JavaScript
- 后端：Node.js + Express，CommonJS
- 部署：GitHub Pages（前端）+ 学校服务器（后端）
- 第一版免登录
- 第一版规则推荐，不接入 AI
- Excel 导入本地处理，后续再做管理员上传页面
- 同名菜品使用不同编号
- 供应状态区分已核实/未核实
- 菜品图片不作为第一版必须字段
- 暂不做实时售罄和活动价格

## 待确定内容

- UI 风格（待产品功能设计文件）
- 学校服务器访问条件和部署方案
- Excel 最终字段和填写规范
- 供应时段精确度
- 密钥和价格单位等细节

## 明确暂缓内容

- 管理员登录和上传页面
- 学生纠错功能
- AI 推荐
- 用户收藏和个性化
- 菜品图片
- 实时售罄和供应状态
- 大小份和活动价格

# 数据模型

## 实体关系

食堂 (1) --< 窗口 (1) --< 菜品

食堂 一对多 窗口
窗口 一对多 菜品

## 关键设计

1. 食堂、窗口、菜品均有唯一编号
2. 窗口编号全校唯一，不重复使用
3. 同名菜品在不同窗口/食堂使用不同菜品编号
4. 菜品关键词独立于菜品名称，支持大类搜索
5. 供应状态区分已核实和未核实，不掩盖不确定性

## 供应状态

- 已核实售卖：实地确认当前有售
- 菜单记录，未核实：出现在菜单上但未确认
- 可能售卖：根据窗口菜品大类推断
- 暂时未售卖：确认当前未售，但后续可能恢复
- 已停止记录：确认不再售卖
- 未知：信息不足
